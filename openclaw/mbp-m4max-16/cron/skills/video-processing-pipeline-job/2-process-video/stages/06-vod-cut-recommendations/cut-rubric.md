# Cut Rubric

Rules for what segments should be flagged for trimming from the published VOD.

## What to flag

- **Sensitive content** — anything matching a category in
  `openclaw/mbp-m4max-16/cron/skills/video-processing-pipeline-job/2-process-video/shared/sensitive-information.md`
- **Segments Kyle explicitly flags** as not appropriate for public viewing

## Principles

- **False negatives > false positives** — empty output is fine, don't pad the list
- **Recommend actual cut intervals with timestamps**, not vague commentary

## How to describe cuts

Describe the risk class broadly, never include the actual secret or exploit mechanics.
