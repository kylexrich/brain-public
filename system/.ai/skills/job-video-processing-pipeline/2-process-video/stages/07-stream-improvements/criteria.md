# Stream Improvements Criteria

Improvements must be **future-stream process changes** — not VOD editing suggestions, not content ideas.

## Requirements

Each recommendation must be:

- **Specific and actionable** — not vague advice like "be more engaging"
- **Grounded in evidence** — something concrete in the stream that showed the need
- **About future behavior** — what to do differently next time

## Examples

- Narrate more during long silent debugging runs
- Set up a clearer BRB / privacy toggle workflow
- Avoid spending long stretches on private admin work on-camera
