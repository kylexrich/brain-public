# Shared Skills

Skills in this folder are available to **all agents** (main + team) via `skills.load.extraDirs`.

Drop a skill folder here with a `SKILL.md` to make it available. Agent workspace skills override these on name collision.

## Bundled Skills Reference

Browse or open the bundled (built-in) skills:

```bash
open /Users/kylerich/.nvm/versions/node/v24.12.0/lib/node_modules/openclaw/skills/
```

List them:

```bash
ls /Users/kylerich/.nvm/versions/node/v24.12.0/lib/node_modules/openclaw/skills/
```

> **Note:** Don't edit bundled skills directly — they get overwritten on updates.
> Copy a skill here to customize it; your version takes priority.
